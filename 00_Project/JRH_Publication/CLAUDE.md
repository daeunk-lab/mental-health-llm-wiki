## 절대 규칙

### 1. 수치는 `00_FACTS.md`가 유일한 기준
어떤 통계도 이 파일을 벗어나지 않는다. 기억이나 추정으로 숫자를 쓰지 않는다.
불일치를 발견하면 즉시 보고하고, 임의로 선택하지 않는다.

### 2. 인용은 검증 없이 쓰지 않는다
- `03_REFERENCES.md`에 ✅로 표시된 것만 원고에 사용
- ❓ 표시 문헌은 DOI 확인 전까지 사용 금지
- 실재하지 않는 문헌을 만들어내지 않는다
- 학위논문 참고문헌 목록에 있어도 서지정보 오류가 있을 수 있으므로 DOI 확인

### 3. 학회 초록의 문항수준 태도 유의성 주장은 금지
학위논문에 근거가 없다. 어떤 문서에도 넣지 않는다.

### 4. 영문 학술 원고 문체
- em dash 사용 금지 → "namely", "including", "that is", 또는 쉼표 삽입구
- APA 7th
- 축약형 금지

### 5. 한국어 응답
- 간결하게. 같은 말 반복 금지
- 근거 없는 칭찬 금지
- 불확실하면 "확인 필요"라고 말할 것

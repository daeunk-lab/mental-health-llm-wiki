## 2. Aim & Scope (검증됨)

심리학과 종교/영성의 협력적 관계, 그리고 종교/영성과 **정신적·신체적 건강**의
관계를 다루는 국제 학술지. 모든 종교 전통의 연구자·전문가로부터
peer-reviewed 원저를 받으며, 논문 유형은 임상적·통계적·이론적·
인상기술적·일화적 접근을 모두 포함함.

→ **함의:** 양적 엄밀성만으로 승부하는 저널이 아님. 질적 자료와
   해석적 논의가 오히려 환영받는 구조.

## 3. 우리 원고에 직접 적용되는 규정 (검증됨)

### 3-1. 초록 250 → 450 단어 확장 가능 ⭐
JRH는 systematic review와 original research의 경우, 해당 reporting
guideline을 충실히 준수하기 위해 필요하다면 **초록을 최대 450 단어까지**
늘리는 것을 명시적으로 허용함.

→ **우리 원고는 convergent mixed methods.** 양적 결과 + 질적 4개 주제를
  250단어에 압축하면 반드시 무리가 감. **450단어 옵션을 활용할 것.**

### 3-2. Qualitative reporting guideline
EQUATOR 목록에서 질적연구는 **SRQR 또는 COREQ**를 제시.
→ 현재 SRQR로 진행 중. 유지.

### 3-3. Statements and Declarations — 별도 타이틀 페이지
본문이 아니라 **별도 title page**에 아래 항목 전부 기재.
누락 시 incomplete로 반송됨.
- [ ] Funding
- [ ] Competing Interests
- [ ] Ethics approval (IRB 위원회명 + 승인번호 + Helsinki 선언 문구)
- [ ] Consent to participate
- [ ] Consent to publish
- [ ] Author Contributions (CRediT 권장)
- [ ] Data availability

### 3-4. Suggested Reviewers ⭐
타이틀 페이지에 **추천 리뷰어 3인 이상** 기재 가능.
기관 이메일 필수. 서로 다른 국가·기관 조합 권장.
→ 우리에게 유리한 옵션. faith-based intervention / spiritual care 연구자
  중에서 미리 확보해 둘 것.

### 3-5. LLM 사용 명시
ChatGPT 등 LLM은 저자가 될 수 없으며, 사용했다면 **Methods에 기록**해야 함.
→ 원고 작성 과정에서 AI를 어느 범위로 썼는지 정리 필요.

### 3-6. 학위논문 기반 논문의 저자 순서
Springer는 학생의 학위논문에 기반한 논문의 경우 **학생을 제1저자로**
두는 것을 권고 (APA Science Student Council 2006 인용).
→ 김다은 제1저자, 김석선 교신저자 구조가 저널 권고와 일치. 문제 없음.

## 4. 우리 원고의 적합성

### 강점
- Faith community(개신교 교회)를 **세팅이 아니라 건강 자원으로** 다룸
- 노인 정신건강 + 영적 돌봄 통합
- Watson / Swanson 이론 기반 → 저널이 선호하는 이론적 접근과 부합
- Intervention Mapping의 체계적 적용
- 혼합연구 → "clinical, statistical, theoretical" 모두 충족

### 약점 (수정 우선순위)
1. **Religion & Health 메시지 부족** — 프로그램 개발 논문으로만 읽힐 위험.
   "왜 교회여야 하는가"가 Discussion에서 명시적으로 답변되어야 함.
2. **태도 결과 비유의** — 정면으로 다루고 해석해야 함. 숨기면 리뷰어가 지적.
3. **단일군 사전사후 + n=39** — 설계 한계. 방어 논리 필요.
4. **일반화 가능성** — 한국 개신교 맥락 → 타 종교·문화권 적용 가능성 논의 필요.

## 5. 확정 사실 (원고 전체에서 절대 기준)

> 박사학위논문 원본 기준. 어떤 문서에서도 이 수치를 벗어나지 않음.

- 표본: 등록 56명 → 참석 46명 → 완료 **39명**
- 지식: t = −3.27, p = .002, Cohen's d = −0.52 (**유의**)
- 태도: p = .540, Cohen's d = **0.10** (**비유의**)
- ⚠️ 태도 **8개 하위영역 전부 비유의**
- ⚠️ 학회 초록의 문항수준 유의성 주장은 학위논문에 근거 없음.
  **본 원고 및 발표자료에 사용 금지.**
- 질적 결과: 4개 주제
